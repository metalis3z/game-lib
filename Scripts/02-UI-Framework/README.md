# 02 - UI Framework

Scripts that run a game's interface as a whole: opening one menu and closing the others, animating windows in and out, hiding the HUD while a menu is open, tabs inside windows, scaling the UI for phones and big screens, and binding keys or gamepad buttons to menus. Most of the copies below are complete, readable controllers written by the games' own developers. Big third-party libraries (Iris, TopbarPlus, Cmdr, Satchel) are not repeated here because they already live in `Scripts/Libraries`. The `_patterns` folder has four clean, standalone modules that combine the best ideas into code you can drop into a new project. Note: a few originals have French or German comments. The code is copied unchanged, and the header of each file explains it in English.

## Techniques seen across games

- **One open window, closed by name.** Almost every game keeps a single `currentlyOpenFrame` value and closes it before opening the next one. Buttons are matched to frames by name (`ShopButton` opens `Frames.Shop`), so adding a menu needs no new code (brainrot-lab, pet-rng, please-donate).
- **Animate a UIScale, not Size or Position.** Tweening a `UIScale` from about 0.8 (or 0) to 1 with `EasingStyle.Back` gives the "pop" look and does not break layouts. Reuse an existing UIScale, because only one per parent is applied (needoh-escape, smash-egg-for-animals).
- **Menus change the world behind them.** Opening a menu tweens a `BlurEffect` up and lowers the camera FOV (70 to about 50-60), and HUD groups slide off toward their nearest screen edge. Disable the blur entirely when it is closed, because a size-0 blur still costs a full-screen pass (drill-and-mine, please-donate, work-at-a-pizza-place).
- **Snapshot and restore the HUD.** Store each HUD element's visible or enabled state before hiding it, and restore exactly that state afterwards, instead of forcing everything back on. Store home positions from the authored copy in StarterGui so a half-finished tween never becomes the new "home" (drill-and-mine).
- **Gamepad is handled per window.** ContextActionService bindings (B to close, L1 and R1 for tabs, a thumbstick radial menu) are bound when a window opens and unbound when it closes. Touch controls that overlap a window are hidden (work-at-a-pizza-place).
- **Scale for the device.** Set the UIScale to `min(screen / referenceResolution)` with a clamp, make touch screens slightly larger, and rescale when `AbsoluteSize` or `ViewportSize` changes. Detect the device from `LastInputType` instead of `TouchEnabled` alone (catalogue-avatar-creator, drill-and-mine, grow-a-garden-2).

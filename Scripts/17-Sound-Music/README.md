# 17 – Sound & Music

Reference scripts for game audio in Roblox: background music and playlists, crossfades, state-driven and area-based music, UI click and hover sounds, volume settings with SoundGroups and saving, positional one-shot sound effects, footsteps, reverb zones and a few special cases (a loudness visualizer, RPM-driven engine sound). Every file is an unchanged copy of the original script with a short header (game, original path, what it does). Some of the best sources (mainly smash-egg-for-animals) have French comments; the header explains each script in English. Many candidate files from grow-a-garden-2, animal-hospital, steal-a-brainrot and escape-kitty-keyboard were left out because they are decompiler output. The `_patterns` folder has four clean, reusable modules that combine the best ideas.

## Techniques seen across games

- **Play music on the client, not the server.** drill-and-mine explains that server-played music can go silent; most games create the music Sound locally in SoundService and give it a watchdog or `Ended` handler.
- **Crossfade with two Sounds.** Fade the old track to 0 and the new one up at the same time with TweenService, then stop or destroy the old one when the tween finishes (big-paintball, brainrot-lab, street-life, pizza place).
- **SoundGroups for volume settings.** Put every Sound in a Music or SFX SoundGroup and let sliders change only the group volume. smash-egg even auto-routes existing sounds (long looped sounds count as music). Save with a debounce and write to the DataStore once per session.
- **One hook for all UI sounds.** Hook `PlayerGui.DescendantAdded` and connect `Activated` / `MouseEnter` on every GuiButton, guarded by an attribute or weak table so a button is never hooked twice. Add a small random pitch so repeated clicks feel natural.
- **Positional one-shots without extra parts.** Parent the Sound to an Attachment on `workspace.Terrain` at the world position (jujutsu, animal hospital), tune `RollOffMinDistance`/`RollOffMaxDistance`, and clean up on `Ended` or with Debris.
- **Areas drive the soundscape.** Invisible zone parts (or ZonePlus) switch music, ambience and `SoundService.AmbientReverb`. Only change things when the zone actually changes, and test against the part's own space so rotated zones work.

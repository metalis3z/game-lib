# 01 - UI Animation

Reference library for Roblox UI animation, curated from 66 unpacked places. Top-level `.lua` files are copies of real game scripts (code unchanged, a 4-line header added: game, original path, scorer categories, what it does; excerpts say which lines). `_patterns/` holds clean, standalone ModuleScripts written from the best techniques seen, ready to drop into a project.

Safety: decompiled / obfuscated / saveinstance output was excluded (several good-looking candidates from Grow a Garden 2, Steal an Egg, Steal a Brainrot and Doors were decompiler output and were studied but not copied). None of the copied files use `require(assetId)`, `loadstring`, `getfenv`/`setfenv`, webhooks or external HTTP. Treat all copied code as reference, not as trusted code. Several smash-egg-for-animals files have French comments (code is unchanged).

Quick picks: start with `_patterns/ButtonFX.lua`, `_patterns/PopIn.lua` and `_patterns/SlideNotification.lua`; read `HoverController_GroupedUIScale__drill-and-mine.lua` and `UniversalButtonFX_TagEffects__brainrot-lab.lua` for real-game examples.

## Techniques seen across games

- **UIScale beats Size tweening.** brainrot-lab, drill-and-mine, smash-egg and punching-simulator all scale buttons through a UIScale. It is one number, it does not fight UIAspectRatioConstraint or UIListLayout, and drill-and-mine notes that Size pulses re-clamped every frame and jittered. Size tweening (pet-rng, animal-hospital) multiplies only the Scale part and shifts neighbours in layouts.
- **Typical numbers.** Hover 1.05-1.10, press 0.87-0.95, hover tween 0.12-0.2 s (Quint/Quad Out), press 0.06-0.1 s, release/bounce 0.22-0.3 s Back Out. Windows open in 0.18-0.5 s Back Out from 80% (or from ~5% for a dramatic grow) and close faster (40-60% of the open time) with Quad/Back In.
- **Back Out is the house style for "pop".** Notifications, reward popups, banners, window opens and tab pops all use Enum.EasingStyle.Back + Out. Exits use In directions (Back In, Quad In) so things accelerate away. Linear is reserved for shimmer sweeps and timers.
- **Cancel before you start.** drill-and-mine keeps the current tween per button and cancels it; smash-egg and steal-an-egg use a token / animation id so a stale Completed handler (from a close that got interrupted by a re-open) does nothing.
- **One loop for many animated things.** Rotating gradients, sunbursts, panning gradients and bobbing icons are all driven from a single Heartbeat/RenderStepped over a registry table instead of one tween or loop per object. drill-and-mine throttles rotation to 30 Hz and both drill-and-mine and smash-egg skip work for hidden UI.
- **Camera + blur sell a window.** Opening a menu often tweens Camera.FieldOfView down (70 -> 50/60/65) and a BlurEffect up (16-24), restoring both on close (drill-and-mine, animal-hospital, please-donate, punching-simulator). drill-and-mine disables the BlurEffect at Size 0 because an enabled blur still costs a full-screen pass.
- **Counters chase, they do not jump.** Currency labels animate the shown value: cubic ease-out over 0.5 s (smash-egg) or exponential lerp displayed += diff * min(1, 10 * dt) (drill-and-mine), and only write Text when the formatted string changes. Gains get a small pop; rapid gains keep it inflated (pop-and-hold) instead of restarting the tween every click.
- **Rolls slow down quadratically and cheat a little.** smash-egg HatchReel runs at full speed for 0.5 s, then slot length = 0.08 + k^2 * 0.62 s; it never repeats the previous item and never shows the result just before landing on it. Tick sound pitch rises per slot. Wheels spin 5+ full turns plus the slot offset with Quint Out over 5 s.
- **Typewriter = MaxVisibleGraphemes.** Set the full text once (layout stays fixed, rich text works) and raise MaxVisibleGraphemes; -1 means "show all". Blip sounds every 2-3 letters with +/-5% PlaybackSpeed. pet-rng even tweens MaxVisibleGraphemes directly with TweenService.
- **Build effects in code, not in Studio.** The best scripts (drill-and-mine ConfettiFX, RebirthRingsFX, ClickEffect; smash-egg RunAlert, ZoneBanner, MoneyHandler) create their Frames, UIStrokes and UIGradients at runtime, so they are portable and need no templates. Ripple rings are just a round Frame with a UIStroke whose Size grows while Transparency goes to 1.

# 04 - Loading Screens

This folder shows how real Roblox games handle the first seconds after a player joins. It covers custom ReplicatedFirst loading screens, asset preloading with a progress bar, skip buttons, studio splash screens, intro cinematics and "intro then pick a team" flows. It also shows how the rest of the game waits for the loading screen to finish before it spawns the character or shows the HUD. Each `.lua` file is an unchanged copy of the original game script. A header at the top gives the source game, the original path and a one-line summary. The four files in `_patterns/` are new standalone modules that combine the best ideas into code you can drop into a project. Many game scripts expect a ScreenGui that was built in Studio (`script.Loading`, `script.UI`, …), so read them for the flow and timing. The code-built ones (smash-egg, steal-a-brainrot-sab-files, flood-escape-2 and the patterns) run without any prepared UI.

## Techniques seen across games

- **Remove the default screen first, then build your own.** Every ReplicatedFirst script calls `ReplicatedFirst:RemoveDefaultLoadingScreen()` straight away and parents a ScreenGui with `IgnoreGuiInset = true`, `ResetOnSpawn = false` and a high `DisplayOrder`. Building the UI in code (smash-egg, sab, flood-escape-2) avoids waiting for a prepared GUI to replicate.
- **Three ways to show progress:** count your own `PreloadAsync` items (pet-rng, sab), watch `ContentProvider.RequestQueueSize` drain (murder-mystery-2, retro-studio, work-at-a-pizza-place), or fake it with a timed bar (smash-egg, scp-tycoon). Real games often mix stages: loaded → data → controllers (rivals-modded).
- **Always offer a way out.** Show Skip after a few seconds (murder-mystery-2 after 7 s, pet-rng, big-paintball). Cap preload time (big-paintball waits at most 2 s for its own assets). Add Studio auto-skip flags so testing stays fast.
- **Preload selectively.** Preloading all of `game` is slow. The better scripts preload the UI first and then a capped number of common models (steal-a-brainrot), or spread the load across frames with a budget.
- **Gate the rest of the game on "loading done".** Use a BindableEvent or an `IsLoadingComplete()` check (drill-and-mine), a player attribute like `IntroState` (smash-egg), or a remote that tells the server to spawn the character (rivals-modded, prison-life). Hide the HUD and core GUI during the screen and restore them afterwards (big-paintball, street-life, murder-mystery-2).
- **End on a moment.** Fade or flash to white, then tween the camera from a high shot down to the player (smash-egg). Or use letterbox bars and a short fly-over before handing control back.

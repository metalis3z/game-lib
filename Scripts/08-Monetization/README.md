# Monetization (receipts, game passes, offers, premium)

How the games sell things: `ProcessReceipt` handlers for developer products, game pass
ownership checks, starter packs with a countdown, Premium perks and purchase announcements.
The most important rule shows up again and again: a receipt must be granted exactly once, even
if the server crashes or Roblox re-delivers it, and must never be marked granted when the item
was not given. Start with `Core_Purchases__steal-an-egg.lua` (receipt ids saved in the profile)
and the `_patterns/` folder, which turns the good ideas into three reusable modules.

## Techniques seen across games

- **Remember every PurchaseId** where it survives a crash: in the profile (`steal-an-egg` ProcessedReceipts) or a PurchaseHistory DataStore (`work-at-a-pizza-place`). In-memory caches (`punching-simulator`) only stop duplicates within one server.
- **Only return PurchaseGranted after the item is really given.** `aura-ascension` and `steal-an-egg` return NotProcessedYet when data is not loaded or a grant fails, so Roblox retries later.
- **Validate anything the client sends.** `drill-and-mine` lets the client pass a context string but checks that the product id matches the configured one, so a cheap product cannot unlock an expensive item.
- **Ownership as attributes** (`drill-and-mine` OwnsGamepass_<key>) lets every script and the client read pass ownership without remotes; check once on join, update on PromptGamePassPurchaseFinished.
- **Limited offers**: one-time packs stored in data (PurchasedPacks), a countdown that only runs during playtime (`drill-and-mine` StoreService), and 'server luck' purchases that boost everyone in the server (`steal-an-egg`).
- **Social proof**: purchase announcements in chat with the buyer's name, verified/premium glyphs and price (`drill-and-mine` PurchaseService).

## Things we did not copy (and why)

- `slime-rng` MonetizationService has a `promptGift` remote that grants a product to another player **without any purchase**. Not copied; its stackable boost idea lives in `_patterns/TimedBoosts.lua`.
- `steal-a-brainrot` ShopService contains a hard-coded username that skips payment and runs the grant directly (a backdoor-style free purchase). Not copied.
- `forsaken` ProductHandler grants products from PromptProductPurchaseFinished (client-side signal, not a receipt) and trusts a client-set gift target. Not copied.
- `grow-a-garden-2` DevProductService is modded to 'fake Robux' instant grants; `dandys-world` and `steal-an-egg-admin` contain decompiled modules; `murder-mystery-2` / `murderers-vs-sheriffs` DataModules call webhooks. None copied.
- `please-donate` Purchases reads gamepass creators to pay booth owners; it is too tied to its UI to be useful and was skipped.

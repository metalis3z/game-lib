# 03 - Notifications

How games tell the player something: short toasts ("Not enough coins"), floating reward text ("+$500"), alert feeds, top-of-screen announcements (admin messages, rare spawns, zone names), danger warnings, yes/no confirmation dialogs, custom ProximityPrompt UI, social nudges (favorite / join group) and gamepass purchase buttons. Every file below is a complete, unchanged copy of the game's script with a short header (game, original path, what it does). Most of them clone a template from ReplicatedStorage or PlayerGui, so you will need to build matching UI or adapt the paths. The `_patterns` folder has four clean, self-contained modules that build their own UI in code and can be dropped straight into a project.

## Techniques seen across games

- **Merge instead of stack.** drill-and-mine and bee-swarm-sim key each toast (kind + text, or item + sign) and update the visible one ("(x3)", "+15 Honey") while restarting its timer. A counter token (`removeToken`) makes old `task.delay` callbacks harmless.
- **Pop with UIScale, fade every descendant.** Instead of tweening Size (which breaks layouts), games add a `UIScale` and tween `Scale` 0 -> 1 with `Back` easing, then fade TextTransparency / ImageTransparency / UIStroke.Transparency on all descendants (or use a `CanvasGroup` and tween `GroupTransparency` once).
- **Fire-and-forget API.** Good notification modules never yield the caller (`task.spawn` inside `show()`), look up the container fresh each call (survives respawn / `ResetOnSpawn`), and simply return if the UI is missing.
- **Yielding dialogs.** Both big-paintball and work-at-a-pizza-place let code write `if Dialog:GetChoice(...) then` and wait for the answer; pizza place adds a per-player queue and a timeout so a server can safely ask a player a question.
- **One remote, many senders.** Server code fires a single `Notify` RemoteEvent with (text, duration, sound, position); admin commands, shops and events all reuse it. For all-server messages, publish through MessagingService and skip your own `game.JobId` to avoid showing it twice.
- **Platform-aware prompts.** Custom ProximityPrompt UIs show the key name on PC and a tap icon on touch (`UserInputService.TouchEnabled`), and gamepad dialogs swap to A/B button icons and set `GuiService.SelectedObject`.

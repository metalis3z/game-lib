# 12 - NPC AI

Reference scripts for non-player characters: monsters and killers that chase players (DOORS-style Figure and Rush, a Backrooms stalker, zombies, an SCP soldier), patrol and wander bots, boss fights and enemy waves, ambient NPCs (customers, seat fillers, idle greeters, a pet-style follower) and NPC dialogue. Every file in the main folder is copied unchanged from one of the unpacked games, with a short header (game, original path, what it does). Most are single Scripts that expect a specific model layout (a `Humanoid`, a `HumanoidRootPart`, child Sounds or Values), so treat them as worked examples to study, not drop-in code. The `_patterns` folder has four clean, reusable modules written from the best ideas here. Some originals have French (smash-egg-for-animals) or Spanish (animal-hospital-horror) comments.

## Techniques seen across games

- **Choosing a target.** Almost every chaser loops over `workspace` or `Players`, keeps the nearest living character within a search radius, and filters by team or tag ("Alive" team in zombie-outbreak, a `findplayer` marker in DOORS, `IsValidTarget` in BotBrain). The better ones add senses: a look-direction dot product plus a raycast for sight (backrooms), speed above a threshold for "hearing" (DOORS Figure), and a perception meter that has to fill before firing (scp-tycoon).
- **Moving.** Three styles appear. (1) `Humanoid:MoveTo` along `PathfindingService` waypoints, re-pathing every 0.5-1 s or when the target moves about 5 studs (sab NpcPathfinding, SimplePath users). (2) Physics movers (`LinearVelocity` + `AlignOrientation`) with smoothed velocity for big bosses that must not trip (smash-egg ZoneBoss). (3) Rail entities that just `PivotTo` / lerp along pre-baked room nodes at constant speed (DOORS Rush). Most also skip pathfinding when the target is close and visible, and call `SetNetworkOwner(nil)` so the server owns the physics.
- **Being fair.** Good chasers give the player a chance: a wind-up before charging, a speed slightly below a well-upgraded player, a leash or give-up timer, safe zones the NPC refuses to enter, and memory that decays instead of perfect tracking (ZoneBoss, scp-tycoon, backrooms FLEE state).
- **Structure.** Clean games use explicit state tables with enter and update functions (backrooms `State = {IDLE, STALK, FLEE, CHASE}`, ZoneBoss `state.Mode`). Free-model style scripts mix everything in one `while wait()` loop and recompute paths every frame, which is the main performance trap when many NPCs exist.
- **Waves and events.** Enemy count grows linearly with the wave number, spawns are batched on a timer at tagged spawn parts, an alive registry decides when the wave is cleared, and bosses switch phase on an HP threshold (`hp <= MaxHp / 2`). Event NPCs (evade / steal-a-brainrot events) are spawned by an EventService with `Start` / `Stop` methods that clean up every connection and model.
- **Dialogue.** Data is a list or tree of `{text, responses}`. Responses carry `next` or an exit line. The UI uses a typewriter effect, turns the NPC toward the player and closes when the player walks away. Only the pizza-place version keeps the conversation on the server, which you need as soon as a choice gives an item or currency.
